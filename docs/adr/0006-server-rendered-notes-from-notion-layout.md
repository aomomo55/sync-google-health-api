# 0006: ノートはサーバーが生成し、Notion のダッシュボード構成を移植する

- ステータス: 採用
- 日付: 2026-10-03

## 背景

利用者は Notion に「ヘルスケアダッシュボード」を作っており、これを Obsidian に移したい。
Notion 側は次の 4 つのデータベースと、それらのグラフで構成されている。

| データベース | 主な列 | 範囲 |
|---|---|---|
| 日次ログ | 日付、歩数、距離km、運動時間（分）、平均心拍、体重kg、8000歩達成 | 直近 90 日 |
| 月次サマリー | 平均歩数、総距離km、運動時間、ウォーキング（分）、平均心拍、平均体重kg、計測日数 | 全期間 |
| 睡眠ログ | 起床日、就寝・起床時刻、睡眠時間、ベッド内時間、中途覚醒、仮眠、7時間以上 | 直近 90 夜 |
| 睡眠 月次サマリー | 平均就寝・起床時刻、平均睡眠時間、平均ベッド内時間、仮眠合計、記録日数 | 全期間 |

Notion のデータも元は同じ Google Takeout なので、移すのはレイアウトだけでよい。

## 決定

- Notion のデータベースの 1 行を Obsidian の 1 ノートにし、列はノートのプロパティ（frontmatter）にする
  - `Health/Daily/YYYY-MM-DD.md`: 日次ログとその朝の睡眠をまとめる。Takeout にステージがあるので、深い・浅い・REM 睡眠の時間を追加する
  - `Health/Monthly/YYYY-MM.md`: 活動と睡眠の月次サマリー
  - `Health/ヘルスケアダッシュボード.md`: 表とグラフを並べたトップページ
- 日次ノートは Notion と違い全期間分作る
- 表は Obsidian 標準の Bases、グラフは Dataview + Charts プラグインで描く
- ノートの本文は Claude に書かせず、サーバーがデータから決まった形式で生成する。Claude は MCP ツール（`sync_health_notes` など）を呼ぶことと、データの分析・コメントを担当する

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| Claude が毎回 Markdown を書く | 柔軟 | 形式がぶれる。Vault を壊す危険があり、トークンも多く使う |
| **サーバーが決まった形式で生成** | 形式が安定し、何度実行しても同じ結果になる | 形式を変えるにはサーバーの改修が必要 |
| 直近 90 日だけ日次ノートを作る | ノート数が少ない | 過去との比較ができない |

## 結果

- 日次ノートは約 1,800 件になり、初回の同期に時間がかかる
- 利用者の Vault に Dataview と Charts プラグインの導入が必要
